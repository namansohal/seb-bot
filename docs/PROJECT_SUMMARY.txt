=====================================
   SEB Bot — Project Summary
   Last updated: October 2026
=====================================

PROJECT OVERVIEW:

An AI assistant that runs in the background on Windows and
provides AI interaction, clipboard operations, screenshot
capture, and persistent Gemini chat functionality.

Learning platform: Ultracode (ultracode.co.il)
Code editor: Monaco editor inside Chrome

=====================================
          TECHNICAL ARCHITECTURE
=====================================

Text Reading:
  Windows UIAutomation API reads text directly from the
  active window.

  The project does not use screenshots or OCR for normal
  text extraction.

  Works with the Monaco editor used by Ultracode.

Tag Detection:
  Regex detects:
    @@TAGNAME: content@@
    @@TAGNAME@@

  Debounce prevents processing while the user is still typing.
  Hash-based deduplication prevents the same tag from being
  processed repeatedly.

  The agent ignores its own terminal window.

AI Provider:
  Multiple AI providers are supported:

    Google Gemini
    Groq
    Mistral

  The provider can be selected automatically based on the
  configured API key or explicitly selected in settings.json.

  Automatic retry is used for rate-limit errors.

Response:
  tkinter is used for the response window.

  Responses can be copied or sent to the editor through the
  available input functionality.

Gemini Chat:
  The project supports persistent Gemini conversations.

  Screenshot-aware chat is also supported:
    @@SSTOCHAT@@ starts a Gemini chat with a screenshot
    @@SSTOSS@@ adds another screenshot to the active chat

  Multiple screenshots can therefore be added to the same
  screenshot-aware conversation.

=====================================
            AVAILABLE TAGS
=====================================

@@ASK: question@@
  Short technical question.

@@ASKALL: question@@
  Question about the code above the tag.

@@SOLVE: task@@
  Requests code based on a task description.

@@SOLVEALL@@
  Processes the complete exercise using the field content.

@@FIX: instruction@@
  Requests changes or corrections to the code above the tag.

@@COPY: text@@
  Places specific text into the Clipboard.

@@COPYABOVE@@
  Places the text above the tag into the Clipboard.

@@COPYALL@@
  Places the complete field content into the Clipboard.

@@CLIPBOARD@@
  Uses the current Clipboard content.

@@PASTE@@
  Inserts Clipboard content through the input mechanism.

@@CHAT@@
  Opens a persistent Gemini chat.

@@SCREENSHOT@@
  Takes and saves a screenshot.

@@SSTOCHAT@@
  Takes a screenshot and opens a Gemini chat with the
  screenshot as visual context.

@@SSTOSS@@
  Takes another screenshot and adds it to the currently
  active screenshot-aware Gemini chat.

=====================================
             SETTINGS
=====================================

api_key
  API key for the selected AI provider.

provider
  ""        = automatic provider detection
  "gemini"  = Google Gemini
  "groq"    = Groq
  "mistral" = Mistral

model
  Model used by the selected provider.

poll_interval
  Configurable polling setting validated by the application.

response_mode
  "auto" = display the response in the response window
  "type" = send the response through the typing mechanism

type_speed
  Controls the typing speed when the typing mode is used.

=====================================
             DAILY USAGE
=====================================

Before using the project:

  1. Run install.bat once to install dependencies.
  2. Configure the API key in settings.json.
  3. Start the agent using start.bat.

During use:

  - The agent runs in the background.
  - Enter one of the supported tags in the editor.
  - Wait for the tag to be detected and processed.
  - Use the resulting response, Clipboard action,
    screenshot, or chat depending on the tag.

For screenshot-aware Gemini chat:

  1. Use @@SSTOCHAT@@ to start the chat with a screenshot.
  2. Use @@SSTOSS@@ whenever another screenshot needs to be
     added to the same active chat.

=====================================
          IMPORTANT NOTES
=====================================

- Keep settings.json private because it contains an API key.
- Do not commit settings.json to Git.
- Use the tag format exactly as documented.
- Tags that require closing @@ must include the closing @@.
- SSTOSS requires an active screenshot-aware Gemini chat.
- SSTOCHAT and SSTOSS are currently implemented specifically
  for the Gemini screenshot-chat workflow.

=====================================
        KNOWN ISSUES / HANDLING
=====================================

SSL errors:
  The project uses the current Google Gemini integration.
  If dependencies are missing or outdated, run install.bat again.

429 Too Many Requests:
  The AI provider layer handles rate-limit retries.

Agent reading its own terminal:
  The project contains logic to ignore its own terminal window.

Tag not detected:
  Check the tag spelling and closing @@ where required.
  Then allow the detection/debounce period to complete.

=====================================
             ARCHITECTURE
=====================================

The project follows a modular design:

  main.py
      |
      +-- reader.py
      |
      +-- detector.py
      |
      +-- tag_handlers.py
              |
              +-- ai_provider.py
              |
              +-- clipboard_utils.py
              |
              +-- keyboard_input.py
              |
              +-- ui_window.py

Each module has a specific responsibility so that tag
detection, AI communication, input handling, Clipboard
operations, and UI functionality remain separated.
