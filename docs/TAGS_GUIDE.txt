=====================================
       TAG GUIDE — SEB Bot
       Last updated: October 2026
=====================================

HOW IT WORKS:

- Type a tag inside the Ultracode code editor
- The agent automatically detects the tag
- The response appears in a popup window or chat window,
  depending on the tag
- AI tags (ASK/ASKALL/SOLVE/SOLVEALL/FIX) are handled by
  Gemini, Groq, or Mistral — the provider is selected based
  on the API key configured in settings.json

IMPORTANT RULES:

- Tags using the @@TAG: content@@ format must end with @@
- Wait for the agent to detect and process the tag
- Tags such as SCREENSHOT, COPYALL, COPYABOVE, SSTOCHAT,
  SSTOSS, and CHAT can be used repeatedly according to
  their purpose
- SSTOCHAT and SSTOSS are intended for Gemini and screenshot
  context

=====================================
       QUESTION & EXPLANATION TAGS
=====================================

@@ASK: question@@
  What it does: Asks a short technical question without
                 using the code in the field
  What you get: An AI explanation/answer
  Example: @@ASK: What is the difference between for and while?@@


@@ASKALL: question@@
  What it does: Asks a question about the code above the tag
  What you get: An explanation/answer about the specific code
  Usage:
      [your code]
      @@ASKALL: Why does the loop not stop?@@

=====================================
             CODE SOLUTION TAGS
=====================================

@@SOLVE: task description@@
  What it does: Requests code based on a description
  What you get: Generated code + option to write it in the editor
  Example: @@SOLVE: Write a C++ function that finds the maximum in an array@@


@@SOLVEALL@@
  What it does: Solves the entire exercise based on everything
                 written in the field
  What you get: Complete solution + option to write it in the editor
  Usage: Write @@SOLVEALL@@ at the end of the field


@@FIX: instruction@@
  What it does: Fixes the code above the tag
  What you get: Corrected code + option to write it in the editor
  Usage:
      int max(int a, int b) {
          return a > b ? a : b;
      }
      @@FIX: Improve the code@@

=====================================
             COPY TAGS
=====================================

@@COPY: text@@
  What it does: Places specific text into the Clipboard
  Example: @@COPY: hello world@@


@@COPYABOVE@@
  What it does: Places all text above the tag into the Clipboard
  Usage: Write it at the end of the code you want to copy


@@COPYALL@@
  What it does: Places the entire field content into the Clipboard

=====================================
          CLIPBOARD / INPUT TAGS
=====================================

@@CLIPBOARD@@
  What it does: Uses the content currently stored in the Clipboard
  Usage: @@CLIPBOARD@@


@@PASTE@@
  What it does: Inserts Clipboard content through the input mechanism
  Usage: @@PASTE@@

=====================================
              CHAT TAGS
=====================================

@@CHAT@@
  What it does: Opens a persistent Gemini chat
  What you get: A chat window where you can continue the conversation
  Usage: @@CHAT@@

  The chat keeps the conversation context during the session,
  allowing you to continue asking questions without starting
  over each time.

=====================================
          SCREENSHOT TAGS
=====================================

@@SCREENSHOT@@
  What it does: Takes a screenshot
  The image is saved with a timestamp
  Usage: @@SCREENSHOT@@
  Note: The tag can be used repeatedly.


@@SSTOCHAT@@
  What it does: Takes a screenshot and opens a Gemini chat
                 with the screenshot as visual context
  What you get: A new Gemini chat with the screenshot available
                as visual context
  Usage: @@SSTOCHAT@@

  Useful when you want Gemini to answer questions about
  what is visible in the screenshot.


@@SSTOSS@@
  What it does: Takes another screenshot and adds it to the
                 currently active Gemini chat
  What you get: The new screenshot is added to the existing chat
  Usage: @@SSTOSS@@

  Important:
  - Start a screenshot-aware chat first using @@SSTOCHAT@@
  - Every SSTOSS use takes a new screenshot
  - The new screenshot is added to the same active chat
  - Multiple screenshots can be added to the same conversation

=====================================
            QUICK SUMMARY
=====================================

------------------+-----+---------------------+---------------------------
@@ASK@@           | Yes | No                  | Answer / explanation
@@ASKALL@@        | Yes | Yes (above)         | Answer about the code
@@SOLVE@@         | Yes | No                  | New code
@@SOLVEALL@@      | Yes | Yes (all)           | Complete solution
@@FIX@@           | Yes | Yes (above)         | Corrected code
@@COPY@@          | No  | No                  | Clipboard
@@COPYABOVE@@     | No  | Yes (above)         | Clipboard
@@COPYALL@@       | No  | Yes (all)           | Clipboard
@@CLIPBOARD@@     | No  | No                  | Uses Clipboard
@@PASTE@@         | No  | No                  | Inserts Clipboard
@@CHAT@@          | Yes | No                  | Persistent Gemini chat
@@SCREENSHOT@@    | No  | No                  | Screenshot
@@SSTOCHAT@@      | Yes | No                  | Gemini chat + screenshot
@@SSTOSS@@        | Yes | No                  | Add screenshot to current chat
