1 What the Project Does

SEB Bot is a Windows-based Python automation tool that watches the currently focused text environment for specially formatted commands called tags.

A tag starts and ends with @@. Once a complete tag has remained stable for the configured debounce period, the application identifies it and dispatches it to the appropriate handler.

  • Reads focused text through Windows UI Automation.
  • Detects supported @@TAG@@ commands.
  • Prevents accidental duplicate processing.
  • Sends AI requests through a provider abstraction.
  • Displays AI responses in a desktop UI.
  • Provides a persistent Gemini chat window through @@CHAT@@.
  • Provides clipboard copy, clipboard inspection, and paste-related keyboard actions.
  • Can capture screenshots as local PNG files.

_DEFAULTS = {
    "api_key": "",
    "provider": "",
    "poll_interval": 1.0,

VALID_PROVIDERS = ("", "gemini", "groq", "mistral")

class ConfigError(Exception):
    """Raised when settings.json contains invalid configuration."""
    pass

def _validate(settings: dict) -> dict:
    if settings["response_mode"] not in VALID_RESPONSE_MODES:
        raise ConfigError(
            f"response_mode must be one of {VALID_RESPONSE_MODES}"
        )

    if settings["provider"] not in VALID_PROVIDERS:
        raise ConfigError(
            f"provider must be one of {VALID_PROVIDERS}"
        )

    if settings["poll_interval"] <= 0:
        raise ConfigError(
            "poll_interval must be greater than 0"
        )

    if settings["type_speed"] < 0:
        raise ConfigError(
            "type_speed must be non-negative"
        )

    return settings
Configuration validation ensures that invalid values are detected during startup instead of silently falling back to unexpected behavior.

6 reader.py — Reading Focused Text

reader.py is responsible for retrieving text from the currently focused Windows UI element.

The reader first checks the focused control, then walks through parent controls when necessary, and finally performs a broader tree search when configured to do so.

reader.py — simplified flow
def read_focused_text() -> Optional[str]:
    try:
        import uiautomation as auto
    except ImportError:
        print("[reader] uiautomation is not installed.")
        return None

    fg = auto.GetForegroundControl()

    if fg and _should_ignore(fg.Name):
        return None

    ctrl = auto.GetFocusedControl()

    if ctrl:
        value = _extract(ctrl)

        if value:
            return value

        parent = ctrl.GetParentControl()

        for _ in range(MAX_PARENT_WALK_UP):
            if parent is None:
                break

            value = _extract(parent)

            if value:
                return value

            parent = parent.GetParentControl()

    if fg:
        return _search_tree(fg, depth=0)

    return None
The reader is intentionally separated from tag detection. Its only responsibility is obtaining text from the Windows UI hierarchy.

7 detector.py — Tag Detection

detector.py recognizes commands using a regular expression and filters them against the project's known tag list.

detector.py — tag recognition
_TAG_RE = re.compile(
    r'@@([A-Za-z]+)\s*:?\s*(.*?)@@',
    re.DOTALL
)

KNOWN_TAGS = {
    "ASK",
    "SOLVE",
    "FIX",
    "COPY",
    "PASTE",
    "COPYALL",
    "COPYABOVE",
    "SCREENSHOT",
    "SOLVEALL",
    "ASKALL",
    "CHAT",
    "CLIPBOARD",
}

peek_tag() returns the latest recognized tag without changing the processed state.

detector.py — peek_tag()
def peek_tag(text: str) -> tuple[str, str] | None:
    candidates = []

    for match in _TAG_RE.finditer(text):
        tag = match.group(1).upper().strip()
        content = match.group(2).strip()

        if tag in KNOWN_TAGS:
            candidates.append(
                (match.start(), tag, content)
            )

    if not candidates:
        return None

    _, tag_type, content = max(
        candidates,
        key=lambda item: item[0]
    )

    return tag_type, content

Duplicate prevention

detector.py — processed state
_processed_hash: str | None = None

def _compute_hash(tag_type: str, content: str) -> str:
    return hashlib.md5(
        f"{tag_type}:{content}".encode()
    ).hexdigest()

def is_new(tag_type, content) -> bool:
    return _compute_hash(tag_type, content) != _processed_hash

def mark_processed(tag_type, content):
    global _processed_hash
    _processed_hash = _compute_hash(tag_type, content)

Debounce

The debounce mechanism prevents a tag from being processed while the user is still typing. The application waits until the detected tag remains unchanged for the configured period.

main.py — simplified debounce flow
while True:
    text = read_focused_text()

    if text and "@@" in text:
        result = peek_tag(text)

        if result:
            tag_type, content = result
            key = f"{tag_type}:{content}"

            if key != pending_key:
                pending_key = key
                pending_since = time.time()
                pending_data = (tag_type, content, text)

            else:
                debounce = (
                    DEBOUNCE_BARE
                    if not content
                    else DEBOUNCE_WITH_CONTENT
                )

                if time.time() - pending_since >= debounce:
                    mark_processed(
                        tag_type,
                        content
                    )

                    threading.Thread(
                        target=_safe_dispatch,
                        args=pending_data,
                        daemon=True
                    ).start()

    time.sleep(MAIN_LOOP_POLL_INTERVAL)

Safe dispatch

main.py — _safe_dispatch()
def _safe_dispatch(
    tag_type: str,
    content: str,
    full_text: str
):
    try:
        dispatch(
            tag_type,
            content,
            full_text
        )

    except Exception as e:
        print(
            f"[Agent] Unhandled error: {e}"
        )

        ui_window.show(
            "ERROR",
            f"Unexpected error:\n{e}"
        )

9 ai_provider.py — AI Provider Layer

ai_provider.py provides a common interface for supported AI services. The application can use Gemini, Groq, or Mistral depending on configuration.

Provider selection

ai_provider.py — detect_provider()
def detect_provider() -> str:
    explicit = Settings.get(
        "provider",
        ""
    ).lower()

    if explicit in (
        "groq",
        "gemini",
        "mistral"
    ):
        return explicit

    key = Settings.get(
        "api_key",
        ""
    )

    if key.startswith("gsk_"):
        return "groq"

    if key.startswith(
        ("AIzaSy", "AQ.")
    ):
        return "gemini"

    return "mistral"

Shared provider abstraction

ai_provider.py — AIProvider
class RateLimitError(Exception):
    """Signals that the request should be retried."""
    pass


class AIProvider(ABC):

    @abstractmethod
    def _request(
        self,
        tag_type: str,
        user_msg: str
    ):
        """Perform one provider-specific request."""

    def generate(
        self,
        tag_type: str,
        user_msg: str
    ) -> str:

        for attempt in range(
            1,
            RETRY_ATTEMPTS + 1
        ):
            try:
                return self._request(
                    tag_type,
                    user_msg
                )

            except RateLimitError:
                if attempt < RETRY_ATTEMPTS:
                    time.sleep(
                        RETRY_WAIT_SECONDS
                    )
                else:
                    raise

Gemini chat sessions

Normal AI tags use individual generation requests. The @@CHAT@@ feature is different: it creates a dedicated Gemini chat session so that messages within the chat can retain conversation context.

ai_provider.py — create_chat()
def create_chat():
    if detect_provider() != "gemini":
        raise RuntimeError(
            "CHAT requires Gemini as the configured provider."
        )

    from google.genai import types

    provider = get_provider()
    client = provider._get_client()

    model = Settings.get(
        "model",
        "gemini-3.5"
    )

    system = (
        "You are a helpful programming assistant. "
        "Answer questions clearly and directly. "
        "Maintain the context of the conversation."
    )

    return client.chats.create(
        model=model,
        config=types.GenerateContentConfig(
            system_instruction=system,
            temperature=0.3
        )
    )
The dedicated chat session keeps the Gemini client alive for the duration of the chat instead of creating a temporary client for every individual message.

AI handlers

  • handle_ask() — sends a short question to the AI.
  • handle_solve() — requests a complete solution.
  • handle_fix() — sends an instruction together with preceding code context.
  • handle_askall() — sends the code above the tag together with a question.
  • handle_solveall() — sends the complete relevant field as the problem.

Utility handlers

  • handle_copy() — copies explicit tag content.
  • handle_copyabove() — copies text preceding the tag.
  • handle_copyall() — copies the complete detected field.
  • handle_clipboard() — prints the current clipboard contents.
  • handle_paste() — performs the configured keyboard paste sequence.
  • handle_screenshot() — saves a screenshot as a PNG file.
  • handle_chat() — opens the Gemini chat interface.

12 keyboard_input.py — Keyboard Input

keyboard_input.py centralizes simulated keyboard operations.

Typing text

keyboard_input.py — type_text()
def type_text(text: str):
    delay = Settings.get(
        "type_speed",
        0.015
    )

    try:
        import keyboard
        keyboard.write(
            text,
            delay=delay
        )
        return

    except ImportError:
        pass

    try:
        import pyautogui
        pyautogui.write(
            text,
            interval=delay
        )

    except ImportError:
        print(
            "[keyboard_input] No keyboard input library available."
        )

13 clipboard_utils.py — Clipboard Utilities

clipboard_utils.py is the single source of truth for clipboard operations.

Copying text

clipboard_utils.py — copy_to_clipboard()
def copy_to_clipboard(text: str) -> bool:
    try:
        import pyperclip

        pyperclip.copy(text)

        return True

    except Exception as e:
        print(
            f"[clipboard] pyperclip failed: {e}"
        )

    try:
        import tkinter as tk

        root = tk.Tk()
        root.withdraw()

        root.clipboard_clear()
        root.clipboard_append(text)
        root.update()

        root.destroy()

        return True

    except Exception as e:
        print(
            f"[clipboard] Tk fallback failed: {e}"
        )

        return False

Reading the current clipboard

clipboard_utils.py — get_clipboard_text()
def get_clipboard_text() -> str:
    try:
        import pyperclip

        text = pyperclip.paste()

        if text:
            print(
                f"[clipboard] Current clipboard ({len(text)} characters):"
            )
            print(text)
        else:
            print(
                "[clipboard] Clipboard is EMPTY."
            )

        return text

    except Exception as e:
        print(
            f"[clipboard] Could not read clipboard: {e}"
        )

        return ""

14 Complete Tag Reference

Tag AI? Context Purpose
@@ASK: question@@ Yes Tag content Ask a short question.
@@ASKALL: question@@ Yes Text above tag Ask a question about preceding text/code.
@@SOLVE: task@@ Yes Tag content Request a complete solution.
@@SOLVEALL@@ Yes Full field Process the complete relevant input as a problem.
@@FIX: instruction@@ Yes Text above tag Request a correction or modification using preceding context.
@@COPY: text@@ No Tag content Copy explicit text to the clipboard.
@@COPYABOVE@@ No Text above tag Copy preceding text to the clipboard.
@@COPYALL@@ No Full field Copy the relevant field to the clipboard.
@@CLIPBOARD@@ No System clipboard Display the current clipboard contents in the console.
@@PASTE@@ No Keyboard action Run the configured keyboard paste sequence.
@@SCREENSHOT@@ System System Capture and save a PNG screenshot.
@@CHAT@@ Gemini Persistent session Open the dedicated Gemini conversation interface.

15 End-to-End Example

Consider the following command: 

@@ASK: Why does my loop not stop?@@
1

main.py starts a polling cycle

The main loop requests the currently focused text from reader.py.

2

reader.py retrieves the text

Windows UI Automation returns text from the focused control or its relevant parent/tree.

3

detector.py recognizes the tag

The regular expression extracts ASK and the question content.

4

main.py starts debounce timing

The detected tag becomes the pending command.

5

The tag remains unchanged

Once the configured debounce interval has elapsed, the command is ready for processing.

6

tag_handlers.py dispatches the command

dispatch() selects handle_ask().

7

ai_provider.py sends the request

The configured AI provider receives the question and generates a response.

8

The response returns

The provider returns the generated text to the handler.

9

ui_window.py displays the response

The result is displayed in the desktop response window.

16 Common Problems and Notes

Do not commit settings.json if it contains a real API key.
Tip: Keep settings.example.json in Git so other installations have a configuration template.
Tip: If a tag is not detected, verify that the tag is present in both detector.KNOWN_TAGS and tag_handlers.HANDLERS.
Tip: @@CHAT@@ requires Gemini because the current persistent chat implementation uses the Gemini chat API.
Debugging: The application prints useful information to the console, including dependency errors, clipboard state, AI request status, and unexpected handler errors.
Message Possible Cause Action
Missing required packages A dependency is not installed. Run scripts\install.bat.
Configuration error An invalid settings value was supplied. Check settings.json against settings.example.json.
Missing API key The API key is empty or still a placeholder. Configure the local settings.json.
429 Too Many Requests The provider rate limit was reached. Allow the built-in retry mechanism to run.
Request cannot be empty An AI tag contains no usable content. Add content between the tag markers.
Tag not detected The tag is not recognized or is incomplete. Check the spelling and closing @@.
Clipboard is empty No text is currently available in the system clipboard. Copy text first, then use the clipboard-related command.
CHAT requires Gemini A non-Gemini provider is currently selected. Configure Gemini as the provider for @@CHAT@@.
